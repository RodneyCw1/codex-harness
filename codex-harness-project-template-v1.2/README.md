先读 [新电脑说明](NEW-COMPUTER.md)，再让 Codex 按 [接入步骤](CODEX-SETUP.md) 使用 `onboard` 合并 project/ 内的规范并完成预检、初始化和基线。执行器独立安装在项目外。目录名保留 v1.2；固定 protocol-v1 保持原件，本机配置与执行行为以外层 v1.3 文档为准。模板没有项目验收结果。
