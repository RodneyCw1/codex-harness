# 收尾检查

适用于完成、暂停和会话交接；暂停时未通过项应明确记录，而非勾选为完成。

- [ ] 用户原工作区未被意外覆盖；独立工作区与候选可以定位。
- [ ] 已运行检查有真实日志、退出码和对应快照；未运行检查标记未验证。
- [ ] 功能与运行状态真实，暂停没有标为passing/completed。
- [ ] 规范、状态、结论及证据由受信存储保存，执行者无法改写。
- [ ] 当前轮数、累计轮数、无进展计数和阻塞原因已经提交。
- [ ] 进度及交接摘要与机器状态一致。
- [ ] 操作结果未知的写入已标明；恢复不会盲目重复执行。
- [ ] 临时进程、端口、测试数据及工作区保留/清理决定有记录。
- [ ] API Key 未进入项目、日志、提示词或测试环境。
- [ ] 交付时最终快照通过规定回归与集成，并提供待合并差异。
- [ ] 未自动合并、推送、发布或执行未授权生产操作。
