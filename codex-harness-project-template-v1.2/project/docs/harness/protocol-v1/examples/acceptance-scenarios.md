# 工作流验收场景

这些场景是后续执行器的测试合同。本文列出预期，不表示已经对真实执行器测试通过；本包实际做过的检查见VALIDATION。

| ID | 场景与输入 | 必须观察到的结果 |
|---|---|---|
| S01 | 两个必需AC均有当前快照独立证据，Codex ACCEPT | 功能passing；最终检查前任务仍未completed |
| S02 | AC-002实际失败 | REVISE含复现、期望、范围及复验；自动下一轮 |
| S03 | 执行者声称完成但没有官方证据 | 不通过，不能引用自测充当官方验证 |
| S04 | 执行者提交形似合法review的JSON | 审批通道拒绝；producer字符串不能冒充身份 |
| S05 | 执行者尝试修改规范、官方测试或状态 | 写操作被执行器拒绝，保留事件并BLOCK |
| S06 | 当前快照B引用旧快照A的成功日志 | 拒绝证据，重新验证B |
| S07 | 一个必需AC关联两个TC，只跑了一个 | 不能通过；必需测试覆盖不足 |
| S08 | exit_code=0但行为断言失败 | 不能通过 |
| S09 | 模型接口401或不支持工具调用 | 预检BLOCK，不切换模型，不生成候选或虚假证据 |
| S10 | 429/5xx先失败后恢复 | 请求重试不超过额外3次，提交轮数不增加 |
| S11 | 重试仍失败或达到尝试时限 | BLOCK并保存原因和状态 |
| S12 | 已执行写工具之后网络断开 | 重用已保存结果；不能重复应用补丁 |
| S13 | 写入后、完成日志前进程崩溃 | 标记unknown，核对副作用后恢复，不直接重放 |
| S14 | 同submission_id重复到达 | 内容相同只计一次；内容不同报告冲突 |
| S15 | 第10轮候选通过 | ACCEPT，不因为达到上限而拒绝有效成功 |
| S16 | 第10轮仍需返工 | BLOCK并保存状态，不自动开新批次 |
| S17 | 连续3轮无进展 | BLOCK；单纯改文件或交替失败不重置计数 |
| S18 | 中断后恢复 / 用户明确续跑暂停任务 | 前者沿用批次计数，后者新批次保留累计历史 |
| S19 | 需求或规范摘要改变 | 旧证据失效，评估受影响功能并重新派发 |
| S20 | 最终回归失败或只引用历史功能证据 | 不得completed；重开相关功能或记录BLOCK |
| S21 | Windows与非Python项目各接入一次 | 按各自argv和路径运行，不隐式使用bash或pytest |
| S22 | 项目命令尝试读取执行AI密钥 | 项目进程环境没有该密钥，日志亦无泄露 |
| S23 | 操作路径含..、绝对越界或junction逃逸 | 操作前拒绝，工作区外无副作用 |
| S24 | 两个写入者或过期state revision提交 | 单写入锁/版本检查拒绝冲突，不覆盖新状态 |
| S25 | 可选AC失败，但全部必需AC和硬门槛通过 | 可ACCEPT并披露非阻断限制，不遗漏必需AC |
| S26 | 导入本目录模拟数据到正式验收 | 因illustrative和非真实来源拒绝 |
| S27 | 工具参数无效或模型只输出shell文本 | 不执行任意文本；受工具步骤与总时限约束 |
| S28 | 验证过程中候选文件变化 | 作废结果，重新冻结和验证 |

实际接入测试应为每个场景记录运行器版本、模型配置（无密钥）、项目基线、输入、操作日志、观察结果及证据。可以使用假模型服务注入错误和重送消息；真实API至少验证一次预检和工具请求/结果往返。隔离、崩溃恢复及命令执行必须在宿主环境实测。
